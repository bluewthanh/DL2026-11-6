Everything here was produced on 2026-10-06 on one machine (an RTX 3060) from the scripts in this repository. All model-vs-model comparisons use the **validation split** (127 images, 909 boxes) with one pycocotools COCOeval. AP is reported ×100.

## Headline results

| | AP | AP50 |
|---|---:|---:|
| YOLOv8n, 448 labelled images (last.pt, 3 seeds) | 44.7 ± 0.7 | 74.9 ± 0.3 |
| YOLOv8n, 45 labelled images (10 %, 3 seeds) | 19.2 ± 2.7 | 36.4 ± 3.4 |
| YOLOv8n, 22 labelled images (5 %, post-hoc, 3 seeds) | 9.9 ± 1.8 | 20.6 ± 3.3 |
| YOLOE-26s zero-shot, bare names | 13.1 | 23.0 |
| YOLOE-26s zero-shot, synonym set (`sea jelly`, `sea star`) | 12.8 | 21.2 |
| YOLOE-26s zero-shot, descriptions | 5.8 | 8.3 |

1. **The YOLOE prompt study reproduces.** All three prompt sets match the documented CPU numbers to within 0.034 AP points, with identical image IDs, ground truth, weights and settings.
2. **Wording effects are class-specific.** `sea star` gives starfish +7.7 AP, and `sea jelly` gives jellyfish −9.9; the overlays show jellyfish relabelled as fish. Descriptions help only starfish and collapse fish and stingray.
3. **Supervised YOLOv8n is far ahead with all labels** (44.4 vs 13.1 for the seed-0 `last.pt`). Zero-shot YOLOE is worth about **22–45 labelled images** (post-hoc bracket, 100-epoch schedule): 10 % of the labels already beats it on every seed, and 5 % does not. The smallest subsets were still improving at epoch 100, so 45 is an upper bound and the true crossover may be lower.
4. **The demo shows the trade-off.** YOLOE accepts new words at inference (`sea star`, `rock`), which YOLOv8n cannot, but it misses many objects in this domain.

## What is stored, so nobody has to re-run a model

- **All predictions** at conf ≥ 0.001, gzip-compressed COCO results:
  - YOLOE: `02_setup2_prompt_study/runs/*/predictions.json.gz`.
  - Every YOLOv8n checkpoint, validation split: `03_setup3_data_efficiency/eval/*/*/coco_predictions_valid.json.gz`.
  - Main YOLOv8n run, test split: `01_setup1_baseline/yolov8n_e100_s0_aquadet/coco_predictions_test.json.gz`.
- **All metrics, configs and training curves** for every run: see each section's README. Every table, plot and overlay here can be rebuilt from these files alone.
- **Not stored:** trained weights (`.pt`), source dataset images/labels, and Ultralytics' batch preview images. Trained weights stay in the Git-ignored `runs/` folder; the source export and generated local views stay in `data/` or `dataset/`. See `README.md` and `DATA.md` for downloads and reproduction.
- **Kept local only:** the raw training console logs. Absolute paths of the machine that ran the experiments were replaced by repo-relative paths in the stored copies; the values are unchanged.

The overlay and demo figures show images from [Roboflow 100 Aquarium v2](https://universe.roboflow.com/roboflow-100/aquarium-qlnqy/dataset/2) (`aquarium-qlnqy`), licensed CC BY 4.0 (see `DATA.md`). Credit the dataset when reusing them.
